# Адвент-календарь «Британский декабрь»

Telegram Mini App: снежный северный городок, 25 домиков-окошек вдоль горного серпантина. Каждый день новое задание одного из пяти типов, выражение дня и карточки для повторения. Когда открыты все 25 окошек, показывается финальный ролик, а 26 декабря приходит сюрприз на Boxing Day. Доступ только для подписчиков твоего канала.

## Как это устроено

Проект состоит из двух частей, которые общаются через Telegram.

| Часть | Файлы | Что делает |
|---|---|---|
| Приложение (сайт внутри Телеграма) | `index.html`, `style.css`, `app.js`, `content.js`, `scene.js`, `icons.js` | Показывает календарь, квиз, карточки. Хранит прогресс в Telegram |
| Бот | `bot/bot.py` | Проверяет подписку на канал, даёт кнопку открытия, шлёт утренние напоминания и сообщение о подарке 26 декабря |

Приложение это обычная веб-страница. Telegram открывает её внутри себя по кнопке бота. Бот работает отдельно: он должен быть запущен на компьютере или сервере.

Что за что отвечает в файлах приложения:
- `content.js` задания, выражения, тексты, песни, ссылки на видео, подарок на Boxing Day. Здесь ты правишь чаще всего.
- `icons.js` картинки для заданий «найди пару».
- `style.css` внешний вид. Цвета интерфейса в блоке `:root`, там же стили света в домиках.
- `scene.js` рисунок карты: горы, серпантин, здания, помощники Санты, Санта с оленями. Список `BUILDINGS` решает, какое здание стоит на месте каждого дня (дом, кафе, банк, пекарня, церковь, почта, отель, ратуша…), его цвет и эмодзи в витрине.
- `app.js` логика: какие окошки открыты, квиз, повторение, сохранение прогресса.
- `index.html` скелет страницы.

## 1. Посмотреть у себя на компьютере

В папке `advent-app` выполни:

```
python3 -m http.server 8000
```

Открой в браузере `http://localhost:8000/?debug=1&today=2026-12-07`.

- `today=2026-12-07` притворяется, что сегодня 7 декабря. Меняй дату и смотри, как загорается свет в домиках: открытые светятся ярко, доступные (сегодняшний и пропущенные) приглушённо, будущие стоят с выключенным светом.
- `debug=1` показывает внизу панель с выбором даты и кнопкой «Сбросить прогресс».
- Без этих параметров приложение работает по настоящей дате. До 1 декабря все окошки закрыты.

## Задания

25 дней поделены на 5 типов, они идут по кругу: лексика, фильм, найди пару, чтение, песня.

| Тип | Дни | Что делает человек |
|---|---|---|
| Лексика | 1, 6, 11, 16, 21 | Выражение дня с примером и вопрос |
| Угадай фильм | 2, 7, 12, 17, 22 | Смотрит отрывок (или читает описание сцены) и выбирает фильм |
| Найди пару | 3, 8, 13, 18, 23 | Соединяет 4 картинки со словами |
| Чтение | 4, 9, 14, 19, 24 | Текст о традиции с вопросами или «правда или выдумка» |
| Песня | 5, 10, 15, 20, 25 | Слушает рождественскую песню и вставляет пропущенные слова |

В любом задании после решения открывается «Выражение дня». Оно попадает в карточки для повторения.

**Видео к фильмам.** Отрывки из фильмов защищены авторским правом. В поле `video` у фильма впиши ссылку на официальный трейлер на YouTube (с канала студии). Пока поле пустое, показывается описание сцены и эмодзи-подсказка.

**Аудио к песням.** Все песни старинные, их тексты свободны от авторских прав, а записи исполнителей нет. Запиши песню сама, положи файл в папку `audio` и впиши путь в поле `audio`. Пока поле пустое, кнопка «Послушать» читает строчки голосом телефона.

**Финал и Boxing Day.** Когда открыты все 25 окошек, сам запускается мини-ролик «Well done!». Свой видеоролик можно подставить в `CONFIG.finaleVideo`. 26 декабря подарок появляется сам при открытии приложения, а бот присылает сообщение. Что лежит в подарке, задаётся в `CONFIG.boxingDay`: по умолчанию это разговорник из всех 25 выражений, сюда можно добавить ссылку или промокод.

Посмотреть всё это заранее: `?debug=1&today=2026-12-25` (открой последний домик) и `?debug=1&today=2026-12-26` (подарок).

## 2. Запустить в Телеграме

1. **Выложи приложение в интернет.** Нужна ссылка с `https`. Подойдут бесплатные хостинги статических сайтов: GitHub Pages, Netlify, Cloudflare Pages. Выкладывай всё, кроме папки `bot`.
2. **Создай бота.** В Телеграме открой @BotFather, команда `/newbot`. Получишь токен. Никому его не показывай.
3. **Создай канал** и добавь бота в администраторы. Без этого бот не сможет проверять подписку.
4. **Настрой бота.** В папке `bot` скопируй `.env.example` в `.env` и заполни токен, имя канала и ссылку из шага 1.
5. **Запусти:**
   ```
   pip install -r requirements.txt
   python bot.py
   ```
6. Открой бота в Телеграме, отправь `/start`.

Бот должен работать круглосуточно, иначе утренние напоминания не придут. Для этого его запускают на недорогом сервере (VPS) или на сервисах вроде Railway и Render. Условия бесплатных тарифов часто меняются, поэтому сначала проверь актуальные.

## 3. Что важно знать про доступ

Бот выдаёт кнопку только подписчикам канала. Но сама страница не проверяет подписку: если кто-то узнает её адрес, он сможет её открыть. Для календаря со словами это нормально. Если позже захочешь настоящую защиту (платный курс, например), понадобится небольшой сервер, который проверяет подпись Telegram (`initData`) и членство в канале.

Окошки открываются по дате на телефоне подписчика (с полуночи). Бот присылает напоминание в `REMINDER_TIME` по часовому поясу `TZ_NAME`.

## 4. Что поменять под себя

- **Слова:** `content.js`, массив `DAYS`. Один блок = одно окошко.
- **Название и год:** `content.js`, блок `CONFIG`.
- **Цвета:** `style.css`, блок `:root`. Поменяй `--postbox` на другой цвет, обнови страницу и посмотри.
- **Интервалы повторения:** `CONFIG.reviewIntervals` (в днях).

## 5. Упражнения, чтобы научиться

Делай по порядку. Каждое занимает 5-15 минут.

1. Поменяй слово в окошке 1 и перезагрузи страницу.
2. Измени `--postbox` и `--lamp` в `style.css` на цвета своего бренда.
3. Добавь второй вариант ответа-ловушку в квиз окошка 5 (массив `options`; не забудь проверить `answer`).
4. В `app.js` найди функцию `isUnlocked` и подумай, как сделать окошки открытыми на день раньше. Подсказка: сравнение с `windowDate(n)`.
5. В `bot.py` измени текст приветствия в функции `welcome` и перезапусти бота.
6. Сложнее: добавь в карточки повторения обратное направление (русский → английский). Нужна новая функция по образцу `renderReview`.
